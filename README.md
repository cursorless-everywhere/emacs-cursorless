# emacs-cursorless

## Background

This was an experimental attempt to make Emacs work with [Cursorless](https://www.cursorless.org/) via a running VS Code sidecar. While the approach was interesting, it has been abandoned.

For those interested in getting Emacs to work with Cursorless, please consider:

1. **Cursorless Emacs Support Discussion**: Follow the ongoing discussion about native Emacs support at [cursorless-dev/cursorless#541](https://github.com/cursorless-dev/cursorless/issues/541)

2. **Cursorless Everywhere Discussion**: See the broader discussion about Cursorless support across editors at [cursorless-dev/cursorless/discussions#2189](https://github.com/cursorless-dev/cursorless/discussions/2189)

3. **cursorfree.el**: A Cursorless-inspired Emacs-native alternative available at [github.com/ErikPrantare/cursorfree.el](https://github.com/ErikPrantare/cursorfree.el)
